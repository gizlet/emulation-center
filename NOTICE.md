# Emulation Center: notices

Emulation Center is free software under the MIT License (`licenses/emulation-center-MIT.txt`).
Its source is at https://github.com/gizlet/emulation-center, and each release attaches it as
`io.gizlet.emulation-center-<version>-source.tar`.

It contains no emulators, games, BIOS or firmware files, and no game artwork. It installs
RetroArch (https://github.com/gizlet/retroarch) and PPSSPP (https://github.com/gizlet/ppsspp)
from the Gizlet Store; each of those packages carries its own notices and corresponding source.

## Runtime

The UI links raylib 6.0 (zlib license) from Gizlet runtime 1, which is part of Gizlet OS and
not included in this package.
